# Security Policy — WRAP-EW2

WRAP-EW2 is a small offline research bench. It is not a hosted product, not a
browser lattice, and not a Bazel monorepo. v1 has no central server and no
telemetry.

## Reporting

Send security reports to **info@Rathor.ai**.

Include a short description, how to reproduce it, and the impact if known.

Do not open a public issue that includes exploit details for dual-use
protocol-break fixtures.

## Scope

Only the latest commit on `main` and open review branches are in scope.
